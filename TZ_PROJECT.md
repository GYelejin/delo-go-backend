# Техническое задание (ТЗ): Платформа проектной деятельности «ДЕЛО»

## 1. Цель проекта
Создание централизованной платформы для студентов и преподавателей, позволяющей публиковать проектные инициативы, находить единомышленников в команды (кросс-вузовские команды Frontend + Backend) и отслеживать прогресс выполнения задач в реальном времени.

## 2. Роли пользователей
1. **Гость**: просмотр открытой витрины проектов, поиск по тегам и технологиям.
2. **Студент-разработчик (Frontend / Backend)**: создание своего проекта, отклик на существующие проекты, управление статусами задач в бэклоге.
3. **Тимлид / Преподаватель (Куратор)**: валидация проектных заявок, распределение участников, оценивание результатов и ведение лидерборда.

## 3. Сущности предметной области
* **Project (Проект)**: `id`, `title`, `description`, `owner`, `created_at`
* **Task (Задача)**: `id`, `project_id`, `title`, `status` (`open`, `in_progress`, `done`), `created_at`

## 4. Архитектурная рамка и API (по стандартам лекции 03)
* Протокол: HTTP/1.1 REST (основной контракт: GET и POST).
* Маршруты:
  * `GET /health` — проверка работоспособности сервиса.
  * `GET /projects` — список проектов (с моковыми данными).
  * `POST /projects` — регистрация нового проекта.
  * `GET /tasks?project_id=1` — получение задач проекта.
  * `POST /tasks` — создание новой задачи.
  * `POST /tasks/status` — обновление статуса задачи (`open` / `in_progress` / `done`).

## 5. Запуск сервиса
* Локальный запуск: `go run cmd/main.go`
* Запуск в Docker:
  ```bash
  docker build -t delo-backend .
  docker run -p 8080:8080 delo-backend
  ```
